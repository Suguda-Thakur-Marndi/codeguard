## 1. Authentication & Security Schemes

CodeGuard enforces four distinct security schemes across its API perimeter:

1. **Public / Unauthenticated**: Health check probes (`/live`, `/ready`, `/health`).
2. **Bearer JWT Token**: Operator and developer sessions for dashboard actions.
   - Header: `Authorization: Bearer <jwt_token>`
   - Roles Enforced: `MEMBER`, `REVIEWER`, `ADMIN`
3. **GitHub Webhook Signature**: Cryptographically verified HMAC-SHA256 signature.
   - Header: `X-Hub-Signature-256: sha256=<hmac_hex>`

- **Request Headers**: `X-Hub-Signature-256`, `X-GitHub-Delivery`, `X-GitHub-Event`.

## 3. External Integration Contracts

### 3.1 GitHub App Integration
- **Protocol**: HTTPS REST API (`api.github.com`).
- **Authentication**: JWT generated using RS256 algorithm and the GitHub App Private Key (`GITHUB_PRIVATE_KEY`), exchanged for an installation access token (`/app/installations/{id}/access_tokens`).
- **Core Endpoints Used**:
  - `GET /repos/{owner}/{repo}/pulls/{number}`: Ingest PR metadata and head SHA.
  - `GET /repos/{owner}/{repo}/pulls/{number}.diff`: Fetch raw unified diff.
  - `POST /repos/{owner}/{repo}/pulls/{number}/reviews`: Post multi-line inline comments.
- **Failure Behavior**:
  - *HTTP 429 / 403 Rate Limit*: Bounded retry with exponential backoff respecting `Retry-After`.
  - *HTTP 502 / 503 Bad Gateway*: 3 automatic retries with jitter before failing job.

---

### 3.2 Google Gemini AI Integration
- **Protocol**: Google GenAI SDK over HTTPS.
- **Models**:
  - Fast Specialist Inference: `gemini-2.5-flash` (`GEMINI_MODEL_FAST`).
  - Deep Reasoning & Adversarial Judge: `gemini-2.5-pro` (`GEMINI_MODEL_REASONING`).
- **Output Schema**: Pydantic models compiled to JSON schema with `response_mime_type="application/json"`.
- **Token Budgeting**: Max token limits enforced per agent prompt; usage recorded in `agent_traces`.
- **Failure Behavior**: Transient network timeouts trigger exponential retry (base 2.0s, max 30s); mock fallback provider available for offline testing (`LLM_PROVIDER=mock`).

---

### 3.3 Zero-Trust Policy Engine Integration (`app.core.policy`)
- **Protocol**: Direct In-Process Python Service.
- **Security Perimeter**:
  - Deterministic Zero-Trust Policy Engine (`apps/api/app/core/policy.py`).
  - Unconditionally blocks 9 forbidden operations (`merge_pull_request`, `repo_delete`, `execute_shell`, `eval_code`, `write_filesystem`, `access_secrets`, `modify_git_history`, `bypass_auth`, `grant_admin`).
  - Audits 100% of consequential tool calls to the immutable `tool_execution_audits` table.
- **Failure Behavior**: Prohibited actions throw `PolicyViolationException` (HTTP 403); rejected policies return deterministic `PolicyDecision(allowed=False, reason=...)` before any GitHub API interaction.
